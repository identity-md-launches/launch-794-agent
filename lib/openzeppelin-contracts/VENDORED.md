# OpenZeppelin Contracts

The five Solidity files and LICENSE in this directory are unmodified files from
OpenZeppelin Contracts v5.0.2, commit
`dbb6104ce834628e473d2173bbc9d47f81a9eec3`:
https://github.com/OpenZeppelin/openzeppelin-contracts/tree/dbb6104ce834628e473d2173bbc9d47f81a9eec3

building and testing requires no package download or git submodule.
